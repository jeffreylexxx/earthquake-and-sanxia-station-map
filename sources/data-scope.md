# 数据范围与官方来源路线

## 水坝分组

- 长江—金沙江干流：中国长江三峡集团、中国长江电力及其官方工程资料。
- 雅砻江：雅砻江流域水电开发有限公司官方工程页面。
- 大渡河：国家能源集团大渡河公司官方页面。
- 岷江：生态环境部工程环评批复。
- 嘉陵江：中国三峡集团长江上中游骨干水库联合调度资料、国家能源局流域划分资料。
- 乌江：中国华电集团乌江梯级资料、中国三峡集团骨干水库联合调度资料，以及重庆市生态环境局／水利局公布的银盘和白马工程资料。

逐条链接、资料日期和所采用字段保存在 `data/dams.seed.json`，地图弹窗直接链接相同来源。

## 地震目录

- 自动来源：USGS FDSN Event Web Service。
- 人工复核入口：国家地震科学数据中心“中国地震台网正式地震目录”。
- 不使用无出处的聚合站、商业免费 API 或媒体转载作为目录来源。

## 滑坡、崩塌与泥石流

- 范围：与地震相同的水坝／简化水道 200 公里走廊，网页默认显示滚动十年。
- 口径：只收录日期明确、地点可定位，并造成伤亡、村镇或重要交通设施受灾，或启动正式应急响应的 A 类重要事件。
- 来源优先级：应急管理、自然资源和地方政府正式通报；中国地质调查局调查研究；缺少前两类页面时采用国家级权威媒体的原始通报。
- 受灾面积：只录入来源明确给出的面积；来源仅给出方量、滑程、户数或疏散人数时，面积保持为空并原样记录官方范围描述。
- 完整性限制：当前不存在字段统一且可稳定公开调用的全国事故 API，本图层是经核验的代表性重要事件集，不宣称覆盖全部地质灾害。

## 特别限制

部分官方页面只公开正常蓄水位、坝高或库容中的一部分，尤其较早投产的小型梯级工程。此类缺项保留为空，不从非官方百科补齐。
